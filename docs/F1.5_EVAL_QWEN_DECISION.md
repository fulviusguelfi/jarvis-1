# F1.5 — Avaliação: Qwen3-4B-Q8_0 vs Qwen3-8B-Q4_K_M

**Decisão:** AINDA ABERTA — requer teste em conversa real

## Modelo Atual (v0.1.0)
- **Qwen3-8B-Q4_K_M** (5.5 GB)
- Estimado: TTFT ~1s, 50-60 tok/s (Vulkan RX 580)

## Candidato (F1.5)
- **Qwen3-4B-Q8_0** (2.4 GB, menos vram)
- Estimado: TTFT <1s, 80-100 tok/s (KV cache menos comprimido)
- Vantagem: velocidade + menos VRAM
- Risco: capacidade reduzida (4B vs 8B parâmetros)

## Critérios de Decisão
1. **Latência:** TTFT + tempo de primeira resposta
2. **Qualidade:** Respostas corretas, tool calling estável
3. **VRAM:** Caberá confortavelmente em RX 580 (8GB)?
4. **Prático:** Conversa natural flui bem?

## Como Testar

```bash
# Mudar em .env
QWEN_MODEL=Qwen3-4B-Instruct-2507-Q8_0

# Testar em conversa real (F1 final)
python src/main.py
```

Fazer perguntas simples e observar:
- Tempo até 1º áudio (TTFT)
- Qualidade de resposta
- Stabilidade de tool calling

## Recomendação Técnica

Se 4B-Q8_0 passar em conversa real:
- Usar 4B como default (benefícios latência + VRAM)
- Manter 8B como fallback/expert mode

Se 4B falhar qualidade:
- Manter 8B-Q4_K_M (4B não tem capacidade suficiente)
